# SafeShare

Сквозное шифрование для обмена файлами между Android-устройствами.

SafeShare использует X25519 ECDH + HKDF-SHA256 для согласования ключей
и получения уникального AES-128-GCM ключа для каждого файла.
Все шифрование происходит на клиенте, а сервер хранит и отдает только
зашифрованные данные.

## Особенности

- **Zero-knowledge архитектура**: сервер никогда не видит открытый текст и ключи шифрования
- **X25519 identity-ключи**: каждое устройство генерирует постоянную ключевую пару в Android Keystore
- **Потоковое шифрование**: файлы шифруются/расшифровываются по частям без загрузки в память
- **Управление контактами**: простой обмен открытыми ключами через QR-коды
- **Подключаемые провайдеры хранения**:
  - **бэкэнд SafeShare**: Rust-сервер с TTL и ограничением числа скачиваний, с поддержкой self-host
  - **Яндекс.Диск**: авторизация через аккаунт Яндекса, сервер не нужен
  - Собственные провайдеры через интерфейс `StorageProvider`

## Быстрый старт

1. Скачайте APK из Releases или соберите из исходников
2. Установите на два Android-устройства (API 31+)
3. На устройстве A: **Контакты** -> **Мой QR**, покажите QR-код устройству B
4. На устройстве B: **Контакты** -> **Добавить** -> **Сканировать QR**. Отсканируйте код устройства A
5. На устройстве A: **Отправить** -> выберите получателя -> выберите файл -> **Начать отправку**
6. Скопируйте или поделитесь кодом передачи с устройством B
7. На устройстве B: **Получить** -> вставьте или отсканируйте код передачи -> выберите место сохранения

Файл шифруется до выхода с устройства A и расшифровывается только на устройстве B.
Сервер (или Яндекс.Диск) никогда не видит открытый текст.

## Сервер (опционально)

SafeShare работает из коробки с сервером по умолчанию [https://medveed.root.sx:6677/](https://medveed.root.sx:6677/).
Если нужен self-host, сборка Rust-бэкенда есть в Releases.

Запуск:

```bash
./safeshare-server
```

Настройка выполняется через переменные окружения:

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `SAFESHARE_PORT` | `8080` | Порт |
| `SAFESHARE_BIND` | `0.0.0.0` | Адрес привязки |
| `SAFESHARE_DATA_DIR` | `./data/files` | Директория хранения файлов |
| `SAFESHARE_DB_URL` | `sqlite://./data/safeshare.db` | Путь к базе данных SQLite |
| `SAFESHARE_MAX_FILE_SIZE` | `1073741824` (1 ГБ) | Максимальный размер загрузки |
| `SAFESHARE_TTL_MAX_SEC` | `604800` (7 дней) | Максимальный TTL файла |

Затем укажите адрес сервера в приложении:
Настройки -> Настройки хранилища -> SafeShare -> URL сервера -> `http://<ваш-ip>:<ваш-порт>`.

## Как это работает

1. Каждое устройство генерирует X25519 identity-ключевую пару, хранимую в Android Keystore
2. Пользователи обмениваются открытыми ключами, сканируя QR-коды друг друга (добавляя в контакты)
3. При отправке файла приложение генерирует эфемерную X25519 ключевую пару и выполняет
   ECDH с открытым ключом получателя для вычисления общего секрета
4. HKDF-SHA256 выводит уникальный AES-128-GCM ключ и nonce из общего секрета
5. Файл шифруется в потоковом режиме и загружается в хранилище
6. Генерируется код передачи, содержащий расположение файла и эфемерный открытый ключ
7. Получатель использует код передачи и свой приватный ключ для обратного ECDH,
   вычисляет тот же AES-ключ и расшифровывает файл

Сервер хранит только зашифрованные данные.
**Даже при его компрометации расшифровать файлы невозможно.**
